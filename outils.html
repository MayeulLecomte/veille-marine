Fabriquer la base de mouillages

Outil de maintenance — à lancer une fois, puis à chaque fois que tu veux rafraîchir les données OpenStreetMap.

Cet outil interroge OpenStreetMap sur les cinq zones couvertes et produit mouillages.json. Une fois ce fichier déposé dans le dépôt à côté de index.html, l'application n'a plus besoin d'interroger Overpass : les points s'affichent instantanément.

Les services à terre. Shipchandlers, carburant, eau, laverie, douches, commerces et restaurants — filtrés pour ne garder que ceux situés à moins d'un kilomètre d'un port ou d'un mouillage connu. Produit services.json, à déposer à côté de mouillages.json.

Fabrique d'abord la base des mouillages ci-dessus : le filtrage s'appuie dessus.

Ensuite :

  1. Touche le lien de téléchargement, ou « Ouvrir dans un onglet » puis Partager → Enregistrer dans Fichiers
  2. Sur GitHub, ouvre le dépôt veille-marine
  3. Add file → Upload files → choisis mouillages.json
  4. Commit changes, puis attends une minute
